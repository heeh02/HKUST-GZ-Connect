## Current support statement

- HKUST(GZ) is the only packaged reviewed school Profile.
- `Other school` is visible in packaged 2.0 builds. It uses a credential-free public probe, one-use exact-origin
  confirmation, isolated storage and persistent unverified presentation; it does not by itself prove password
  auth, L3, Campus DNS, MFA or resource support.
- The repository supports multiple isolated Profile candidates and one active Profile at a time. It does not yet
  claim formally reviewed multi-school production compatibility.
- The production Gateway provider remains password + Modern L3. Generic MFA/control types and synthetic tests
  do not constitute a real school MFA provider.

## Local beta evidence

- `/Applications/hkustgzconnect.app` is the sole retained local App and reports `2.0.0-beta.1`.
- Package verifier and `codesign --verify --deep --strict` passed with an Apple Development identity.
- The packaged arm64 Engine depends only on `/usr/lib/libiconv.2.dylib` and `/usr/lib/libSystem.B.dylib`.
- Installed Engine startup reported assigned Campus IP, Gateway DNS and a loopback listener on `127.0.0.1:6180`.
- A SOCKS request to the school homepage returned HTTP 200. The HPC hostname resolved and completed HTTPS;
  the tested `/login` path returned HTTP 404 rather than a DNS/tunnel failure.
- This is local staff test evidence, not a published release or another school's compatibility proof.

## Active order

1. obtain user visual and ordinary-use acceptance of the installed `2.0.0-beta.1` package;
2. keep the exact v1.2.3 migration fixture and three-platform package gates green before Phase 5 delivery;
3. add a second reviewed Profile before claiming reviewed multi-school compatibility;
4. implement real Gateway capabilities only from authorized, sanitized school evidence;
5. publish `2.0.0` only after the remaining release gates are explicitly approved.

The application remains Web-resource-first for ordinary users and exposes external-tool configuration for
advanced users. It does not add an SSH client, HPC manager, Jupyter/database launcher or `ForwardLease`.
