# 2.0 Capability Matrix

状态：Planning evidence；固定代码快照需要在每次正式评审时更新。

本矩阵比较的是可验证工程能力，不是功能数量排行榜。zju-connect 和 EasyConnect 的
条目只表示固定观察/源码证据；未在 HKUST(GZ) 同一 profile 验证的行为不能直接迁移。

## 1. Evidence model

### Implementation level

- `I0`：无实现；
- `I1`：类型、接口或 classifier；
- `I2`：offline parser、synthetic provider/backend；
- `I3`：接入 production path；
- `I4`：多个 production provider/backend。

### Evidence level

- `E0`：无证据；
- `E1`：source/contract review；
- `E2`：unit/property/synthetic；
- `E3`：packaged/cross-platform integration；
- `E4`：授权 HKUST 真实 canary；
- `E5`：同 profile 官方客户端 parity。

专有协议能力只有至少 `I3+E4`，并完成适用的官方 parity，才可以对用户标为 Supported。

### Fact labels

- `Observed`：学校网关或官方客户端在固定日期/profile 实际观察；
- `Confirmed`：当前固定 commit production path 和匹配测试直接证明；
- `Hypothesis`：外部仓库、厂商包或相邻部署只提供线索；
- `Unknown`：没有本校证据和 production 实现。

## 3. Engineering scorecard

### Correctness and routing

- 128 条规则 decision p95 `<0.5 ms`；
- 100,000 个 property corpus 中 JS/PAC/Rust/Exit mismatch `=0`；
- policy transaction 期间越权请求 `=0`；
- rollback incomplete 时 Browser 继续请求 `=0`；
- 每个内部 decision 有 exit/source/revision/generation；完整 URL 不落日志。

### Stability

- 100 次 connect/disconnect/reconnect 无残留 Engine、listener、timer、thread；
- 1,000 次 parser/network fault injection crash/panic `=0`；
- interface generation 变化后旧 socket/request 继续发送 `=0`；
- unknown capability 隐式 downgrade `=0`；
- 单网站失败被误判为隧道失败 `=0`。

### Security

- 非 loopback listener `=0`；
- Gateway 隐式环境代理使用 `=0`；
- campus DNS 失败时 system/public DNS packet `=0`；
- invalid TLS matrix 拒绝率 `100%`；
- direct DNS rebinding 到 loopback/private 拒绝率 `100%`；
- package 中真实 secret/test key/fake gateway `=0`；
- 100 次强杀后系统 DNS/route/proxy 残留 `=0`。

### Performance

- SOCKS/frontend offline p95 `≤10 ms`；
- netstack offline matrix p95 `≤10 ms`；
- 相对固定 1.x 同机基线 throughput/latency 回退 `≤5%`；
- 20 标签切换 product p95 `<100 ms`；
- tray idle CPU 中位数 `<1%`；
- 30 分钟 20-tab soak，排除有界 cache 后内存净增长 `<5%`。

### Observability

- terminal failure stable code 覆盖 `100%`；
- DNS 区分 cache/UDP/TCP/negative/timeout，默认不记录 hostname；
- route 只记录 Exit/source 聚合；
- Gateway latency标记实际 underlay或 `system_route`；
- 日志大小和三天期限强制执行；
- diagnostic mode 默认关闭并自动到期。

### Maintainability and release

- CommonJS/Rust boundary cycle `=0`；
- 新跨层 import 在 CI fail；
- 每个 production provider 有独立 fixture、rollback 和 owner；
- 每个 release 的源码 SHA、四平台产物、native 架构和 package manifest 可复现；
- release capability 状态同时记录 implementation 与 evidence，不能只写 Done。

## 4. Promotion rule

每项能力的矩阵升级必须附上：固定 commit、测试/CI run、需要时的真实 canary、失败边界、
rollback 和文档更新。接口或 synthetic 测试只能提升到 I1/I2/E2，不能代替 I3/E4。
