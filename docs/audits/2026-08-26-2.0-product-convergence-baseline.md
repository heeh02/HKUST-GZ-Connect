- Audit date: 2026-08-26
- Goal authority: the 579-line approved 2.0 convergence objective attached to the active Codex goal
- Source baseline: `de35d652fe5cb4681830782a2929d20f4eca9df3`

- Published stable line: `v1.2.3` at `5d8323d37de7c279ae70b3ec646f93791d6a3581`
- Development version: `2.0.0-beta.0`
- Release decision: NO-GO; no commit, push, package replacement or release is authorized by this baseline

This audit freezes the evidence at the start of the product-convergence goal. It does not promote a working-tree
implementation to released or school-verified support. `docs/2.0-status.md` is the short mutable index; this file
records the Phase 0 evidence and requirement gaps.

## 1. Repository state

The baseline `main` and `origin/main` trees were byte-identical at `de35d65`. The pre-existing product-correction
worktree contained 117 tracked paths with 2,282 added and 4,179 deleted lines, plus new bounded modules for atomic
exports, Custom Profile deletion and Student Home. The deletions predominantly remove the retired Clash Verge and
OpenSSH managed install/update/remove lifecycle.

The worktree was moved without reset or cleanup onto the single required development branch
`codex/2.0-product-convergence`. The obsolete remote `codex/2.0-macos-icon-compat` branch had the same tree as
`origin/main` and was removed. The remaining remote product branch is `origin/main` until this convergence branch
is deliberately pushed.

No user credential, Browser data, local settings or installed application was modified during Phase 0.

## 3. Verified local baseline

### Desktop

- `npm test`: 981 tests, 980 passed, 1 platform-conditional skip, 0 failed.
- `npm run check:architecture`: PASS; 371 files, 725 edges, no cycle, root debt 0,
  `main.js` 1,659 lines and `renderer/app.js` 564 lines.
- JavaScript syntax and tracked-secret gates: PASS.
- Real Electron gates: responsive layout, Campus MFA, popup MFA, Custom Profile startup, Profile switch recovery,
  school onboarding and v1.2.3 persistence migration all exited successfully.

The first Desktop run found one real architecture regression: notification styling added four lines to the
ratcheted root Renderer. It was fixed by extracting `renderer/notification-view.js`; the architecture ceiling was
not raised.

### Rust

- Rust 1.97.1 formatting: PASS.
- Clippy `-D warnings`: PASS.
- Test result: 297 passed, 0 failed, 2 explicitly ignored offline performance matrices.

The first shell invocation lacked Cargo subcommands and `rustdoc` on PATH. The fixed 1.97.1 toolchain binaries
were invoked explicitly; this was an environment-path issue, not a source failure.

## 4. Confirmed open work

1. Complete the Design Token and all-page Phase 1 visual implementation, then capture 420/620/960 Electron
   evidence in both languages and at 200% zoom.
2. Remove remaining generic HKUST defaults that are not intentional product branding or legacy migration aliases.
3. Add explicit Browser-data clearing without coupling it to VPN credential removal or Profile deletion.
4. Make `CapabilitySnapshot` and typed recovery actions the single user-visible capability/error truth.
5. Produce a repeatable sanitized EasyConnect version-diff receipt without committing vendor binaries.
6. Add a second reviewed test Profile before claiming formal multi-school support.
7. Complete migration, macOS/Windows/Linux package verification, local application replacement and user testing
   before changing the release state.

## 5. Non-goals retained

The convergence goal does not add an SSH client, HPC manager, Jupyter/database launcher, RemoteApp,
third-party software installation, TUN, global DNS mutation, default-route mutation or speculative MFA endpoints.
