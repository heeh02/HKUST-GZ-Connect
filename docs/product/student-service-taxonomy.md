# HKUST(GZ) Student Service Taxonomy

This file is the reviewed product source for the HKUST(GZ) Campus Workspace
classification. It groups systems by a student's task instead of the department
that owns the system. URLs remain in the reviewed Profile asset; this document
records why each category exists and what search vocabulary it must cover.

## Rules

- A system has one primary task category and may have multiple search keywords.
- Prefer a stable official directory over a guessed or semester-specific deep link.
- A generic application system may appear once and use keywords for its supported
  tasks. Do not create duplicate cards for every form in the same system.
- Role-specific systems are allowed when their audience is clear in the title or
  description. Inclusion does not imply that every account is authorized.
- Direct/Campus routing remains independent from the visual category.
- Custom Profiles inherit the taxonomy vocabulary but never HKUST(GZ) URLs.

## Student task categories

| Category | Typical student intent | Reviewed entry examples |
| --- | --- | --- |
| Getting Started | 入学、报到、学籍、专业选择、转学分 | NSO, SIS, UG Major Selection, UG Credit Transfer |
| Classes & Exams | 上课、课表、选课、考试、成绩、教室 | Canvas, Class Schedule, Enrollment Request, Room Booking, Academic Calendar |
| Research & Labs | 科研项目、论文、实验、仪器准入与预约 | Thesis Exam, LIMS, Instrument Sharing, RPMS |
| Fees & Expenses | 学费、住宿费、奖学金、项目经费、采购与报销 | SFS, PBMS, E-Tender |
| Career & Internships | 实习、校招、就业活动、职业辅导 | Career Center |
| Campus Life | 宿舍、校园卡、交通、社团、勤工助学、IT/HPC 申请 | One-stop Service |
| Requests & Leaving | 请假、休学、转专业、证明、成绩单、毕业与离校 | Student Request Guide, E-Form, Academic E-Doc, E-Doc Verification |
| General Tools | 官方门户、邮箱、IT 指南和学校公开入口 | myPortal, Outlook, ITD, School Homepage |

## Maintenance boundary

The reviewed resource asset may contain at most 32 entries. Before adding or
changing an entry, verify the official source, stable canonical URL, audience,
Campus/Direct route, localized name, task category, and search keywords. Dynamic
semester links and SSO callback URLs must never be stored as reviewed resources.
