# HKUST(GZ) Connect 学生优先界面收束方案

> 状态：已获用户批准并进入 Goal 实施
> 日期：2026-09-01
> 依据：当前安装版实机截图、无上下文学生盲测、已实施 Card Board 数据与安全合同

## 1. 唯一设计原则

> **简单简洁就是美。**

这里的“简单”不是减少能力，而是让能力只在需要时出现：

- 一个页面只有一个主要任务；
- 一个区域只有一个主要动作；
- 能删除的容器不再用颜色装饰；
- 能用文字说清的动作不用神秘图标；
- 高级信息默认收起，但仍然可达；
- 动效只解释状态变化，不负责制造高级感。

每次新增视觉元素前都必须回答：它是否帮助学生更快完成任务？如果不能，删除。

## 2. 本轮结论

### 2.1 当前截图为什么难看

问题不在“白色不好看”，而在错误的结构重复：

1. 12 个分类被塞进一个牌堆，退化成一列超长手风琴；
2. 每一行都使用相同圆角、边框、图标和高度，没有主次；
3. 巨大白色外框中又嵌套 12 张白卡，形成无意义的两层容器；
4. 同一个四宫格图标重复 12 次，既不能帮助识别，也增加噪音；
5. 窄窗侧栏占用过多宽度，“校园浏览器”还被迫换行；
6. 当前活动卡只靠略深边框区分，既不像抽出的牌，也不像明确的展开项；
7. 内容很长，但没有清楚告诉用户当前牌堆、活动卡和剩余分类的关系。

因此继续调整白色、蓝色或阴影不会解决问题。必须先减少重复结构。

### 2.2 无上下文学生盲测结论

盲测者仅知道产品用途，没有获得按钮说明、设计目标或历史问题。

通过项：

- 10–15 秒理解“校园连接 + 校园网站 + 高级工具”；
- 5–8 秒找到课程与成绩入口；
- 7–10 秒搜索并打开 HPC2；
- HPC2 打开前后都能确认使用校园隧道；
- 当前纯白、深蓝和少量金色的品牌方向可以保留。

卡壳项：

- `+`、`整理`、`打开浏览器`需要猜；
- 连接页的源 IP、DNS、TUN、活动连接等术语过早出现；
- 卡片像表格/手风琴，不像可抽取和整理的牌；
- 大分类展开后会把其他内容推离视口；
- HPC2 打开时存在无反馈的纯白加载阶段；
- 搜索“报销”等自然语言时，结果缺少用途和适用人群说明。

独立评分：功能 8.0/10，GUI 7.3/10。

## 3. 产品信息架构

侧栏继续只保留四个入口：

```text
顶部：连接 / 校园浏览

底部：控制塔 / 设置
```

职责不交叉：

| 页面 | 唯一主要任务 | 默认不显示 |
| --- | --- | --- |
| 连接 | 连接学校网络并确认是否可用 | 完整网卡树、DNS、TUN、诊断明细 |
| 校园浏览 | 找到并打开校园网站 | 网络规则编辑、连接参数 |
| 控制塔 | 修改高级连接与集成配置 | 收藏、校园分类 |
| 设置 | 应用偏好、隐私、更新、状态诊断 | 校园网站和连接拓扑 |

通知不回到侧栏。“通知与帮助”改为更准确的“状态与诊断”；真正的新手说明放在各功能第一次使用时。

## 4. 校园浏览器：新骨架

页面删除“网站分类”巨大外层白卡。页面背景直接承载标题、搜索、来源切换和牌堆。

### 4.1 默认窗口 1024×576

```text
校园浏览器                              [打开校园浏览器]
按用途查找学校网站                      [添加网站] [整理]

[ 搜索网站、用途或分类                                      ]

校园服务    我的分类                                  12 个分类
────────

┌ 牌堆 A ─────────────┐  ┌ 牌堆 B ─────────────┐
│ 综合入口          3  │  │ 实验室与仪器      2  │
│ 课程、选课与成绩 10  │  │ 学费、奖助与津贴  2  │
│ 科研、进度与计算  7  │  │ 经费、采购与报销  2  │
└─────────────────────┘  └─────────────────────┘

┌ 牌堆 C ─────────────┐  ┌ 牌堆 D ─────────────┐
│ 申请、证明与毕业  5  │  │ 协作、图书馆与 IT 7 │
│ 住宿与空间        2  │  │ 入学、账号与迎新  2 │
│ 实习、就业与发展  1  │  │ 教师与行政        2 │
└─────────────────────┘  └─────────────────────┘
```

12 个分类不再组成一叠 12 张，而是稳定分成 4 叠、每叠 3 张。

### 4.2 窄窗口 440×540

- 侧栏缩为 64px 图标栏，完整名称通过 tooltip 和无障碍标签提供；
- 主内容边距 16px；
- 标题操作使用“打开”“添加”“整理”三个短文字按钮；
- 仍为 4 叠 × 3 张，单列自然滚动；
- 不把 12 个分类重新压回一个超长牌堆；
- 不出现横向滚动。

### 4.3 宽窗口

- 1180px：3 列；
- 1440px：最多 4 列；
- 主内容最大宽度 1240px，避免无限拉伸；
- 卡片内容变宽时只增加留白，不增加第三列网站。

## 5. 牌堆规则

### 5.1 自动牌堆最大深度固定为 3

当前算法的根本问题是“槽位少就把所有卡塞进同一叠”。新规则：

```text
maxAutoStackDepth = 3
deckCount = max(可见槽位数, ceil(分类数 / 3))
```

结果：

| 分类数 / 环境 | 结果 |
| --- | --- |
| 6 个分类、3 个槽位 | 3 叠 × 2 张 |
| 12 个分类、窄窗 | 4 叠 × 3 张，单列滚动 |
| 12 个分类、默认窗 | 4 叠 × 3 张，2×2 |
| 12 个分类、宽窗 | 4 叠 × 3 张，一排四叠 |
| 高度充足且槽位增加 | 稳定拆成更多浅牌堆，最终可全部展开 |

自动分组只影响响应式投影，不写入持久化布局。用户手动建立的牌堆继续持久化。

### 5.2 视觉结构

- 一叠最多露出 3 个标题；
- 卡片圆角 12px，不使用接近胶囊的超大圆角；
- 后层卡片左右各缩进 4px，形成真实层次；
- 后层无大阴影，仅 1px 中性边框；
- 当前牌使用一条 2px 深蓝侧脊和轻阴影；
- 不使用分类彩虹色、渐变或厚金边；
- 数量与展开箭头位于右侧，点击意图明确。

### 5.3 分类图标

删除重复四宫格。使用本地内置、统一线宽的语义图标：

```text
综合入口：指南针       课程成绩：书本/学位帽
科研计算：烧瓶/节点    实验仪器：显微镜
奖助津贴：钱包         采购报销：票据
申请毕业：文件勾选     住宿空间：房屋
就业发展：公文包       图书馆 IT：书架/终端
入学迎新：用户加号     教师行政：证件
```

图标容器 24px，图标本体 14–16px。图标帮助识别，但不承担唯一语义。

## 6. 原位抽卡

点击任意标题后：

1. 卡片仍在当前牌堆、当前位置；
2. 该卡提升为前景并展开；
3. 同叠其他卡只保留标题；
4. 其他牌堆不改变活动卡；
5. 页面不自动滚到底部；
6. 焦点跟随被点击卡片。

小卡首次只展示 4 个网站；中卡 6 个；大卡 8 个。超过数量显示“查看全部 N 个”，第二次明确操作才展开完整列表。

网站区域：

- 卡片内容宽度不足 360px：1 列；
- 达到 360px：2 列；
- 永远不超过 2 列；
- 名称最多两行；
- 图标 24px，收藏星 16px；
- “直连 / 校园隧道”提高文字对比度，不使用大色块；
- 不使用永久内层滚动条。

动效：

- Hover：120ms，仅边框和 1px 抬升；
- 原位展开：200–220ms；
- 布局重排：240ms FLIP；
- 不弹跳、不旋转、不模糊；
- Reduced Motion 下立即完成。

## 7. 搜索与 HPC 场景

搜索时暂时退出牌堆，使用扁平结果：

```text
HPC2 登录节点
高性能计算集群登录入口 · 研究生 / 博士
校园隧道                                      [打开]
```

排序优先级：

1. 网站名称精确匹配；
2. 网站关键词匹配；
3. 用途描述匹配；
4. 分类名称匹配。

分类名称命中不能再无差别返回整个分类。结果增加：

- 一句用途说明；
- 适用人群；
- 网络路径；
- 匹配词高亮。

打开 HPC2 等网站时，立即显示本地加载状态：

```text
正在打开 HPC2 登录节点
通过校园隧道连接…
[取消]
```

加载状态不得读取或显示凭据。超过合理时间后显示重试，不留下纯白页。

## 8. 连接页

连接仍是核心，但首屏只展示普通学生真正需要的信息：

```text
香港科技大学（广州）                    [已连接开关]
● 已连接

校内 IP                 延迟              当前出口
10.x.x.x                18 ms             Wi‑Fi · 默认直连

[切换网卡与查看网络路径]
[更多连接信息]
```

完整网卡树、公网出口、本机地址、TUN、系统代理和 DNS 放入“切换网卡与查看网络路径”。它们不删除，只做渐进披露。

文字修正：

- “活动连接 0”改为“当前没有应用正在使用校园隧道”；
- “源 IP”在普通界面改为“本机地址”；
- 技术名词旁提供一句人话说明；
- 默认真实网卡标注“默认直连”。

连接开关、状态和错误恢复仍属于固定安全区，不能拖动或隐藏。

## 9. 高频按钮与整理模式

默认窗口使用完整文字：

```text
[打开校园浏览器] [添加网站] [整理分类与网站]
```

不再把主要动作表示为单独 `+`。

进入整理模式后，页面标题区变为：

```text
拖动卡片调整位置；拖到另一张卡片中间可叠放
[撤销] [重做] [恢复默认]                       [取消] [完成]
```

- 普通模式绝不启用拖动；
- 整张卡片可拖动，不显示多余拖动手柄；
- 插入、叠放、抽出使用不同落点反馈；
- 保存只提交布局，不改变收藏、分类内容或网络规则；
- 用户可把分类卡固定到连接页，但连接控制本身不可移动。

## 11. 工程边界

保留现有 Card Board 数据、安全和持久化合同，只调整投影与界面：

- 不修改 EasyConnect Engine、认证、路由或凭据；
- 不把分类内容复制进布局文档；
- 不保存颜色、HTML、URL 或像素坐标；
- 自动牌堆的物理分组不持久化；
- 手动顺序、手动牌堆和尺寸继续持久化；
- 搜索、加载状态、连接摘要分别独立组件，不塞回 `app.js`；
- Windows、macOS、Linux 共用同一响应式规则。

建议新增/调整的独立模块：

```text
card-board-projection.js     最大深度 3 的稳定发牌
card-board-icons.js          本地语义分类图标
card-board-view.js           标题、计数、箭头、内容预览
campus-search-presenter.js   精确排序、用途与人群摘要
browser-loading-view.js      路由可见的加载/失败状态
connection-summary.js        普通摘要与高级树之间的投影
```

## 12. 实施顺序

### Phase 0：先锁定 RED

- 12 个分类在窄窗不能形成一叠 12 张；
- 单个牌堆最大 3 张；
- 主要按钮必须有文字；
- 点击卡片位置不变、页面不自动滚动；
- 小卡默认最多展示 4 个网站；
- HPC 加载首帧有反馈；
- 连接首屏不直接展示工程术语。

### Phase 1：校园浏览器骨架

- 删除巨大外层白卡；
- 修正侧栏窄窗模式；
- 完整文字按钮；
- 4 叠 × 3 张的默认投影。

### Phase 2：卡片与整理

- 语义图标；
- 原位抽卡；
- 4/6/8 内容预览；
- 插入、叠放、抽出与键盘操作。

### Phase 3：搜索与真实网站加载

- 精确排序；
- 用途、人群、路径；
- HPC2 加载与失败状态。

### Phase 4：连接页渐进披露

- 核心首屏；
- 紧凑出口摘要；
- 高级网卡树折叠；
- 人话术语。

### Phase 5：验证

- 单元、Electron、视觉回归；
- 440×540、1024×576、1180×900、1440×900；
- 125% / 200% 缩放；
- 键盘、Reduced Motion；
- macOS、Windows、Linux；
- 新的无上下文学生盲测。

## 13. 验收标准

必须全部满足：

1. 截图中的 12 条长白条不再出现；
2. 任意自动牌堆最多 3 张；
3. 默认窗口显示 4 个清楚的牌堆，而不是两列手风琴；
4. 窄窗侧栏不挤占主要内容，且无横向溢出；
5. 课程、报销、证明、图书馆和 HPC2 都能在 20 秒内找到；
6. HPC2 从点击开始立即显示“通过校园隧道打开”；
7. 用户无需猜测 `+`、`整理`、`打开浏览器`；
8. 点击卡片原位展开，不滚到底部；
9. 连接状态、开关、IP 和延迟始终首屏可见；
10. 普通学生默认不需要理解 DNS、TUN、源 IP 和代理术语；
11. 第二次独立盲测功能评分不低于 9/10，GUI 不低于 8.5/10；
12. 不修改连接引擎，不降低现有安全、跨平台和持久化测试。

## 14. 待批准的锁定决策

批准本文等于同时批准：

1. **简单简洁是最高设计原则；新增视觉前先删除冗余。**
2. **自动牌堆最大深度固定为 3。**
3. **删除校园浏览器的大外层白卡。**
4. **普通分类全部纯白，不使用分类彩虹色。**
5. **主要操作使用文字按钮，不再单独使用 `+`。**
6. **连接高级网络信息保留，但默认折叠。**
7. **继续使用现有 Card Board 数据合同，不重写连接引擎。**

本文已绑定当前执行 Goal；实现必须继续满足上述锁定决策与验收标准。
